Camera probe

Reports the pixel size of a photo from each capture path. No photo leaves this phone.

Test 1: system camera

If the camera screen has a 50 MP or high-resolution mode, select it.

Test 2: photos from gallery

Open the phone camera app. Select 50 MP mode one time. Take 3 photos in sequence. Then select all 3 here.

Test 3: camera inside the page

Needs HTTPS. Repeat for each camera in the list.

Test 4: read the camera folder

Android only. Select the folder with the camera photos (DCIM, then Camera). The page reads file sizes and times. It reports no file names.
